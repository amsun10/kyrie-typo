# Kyrie's Typo ⌨️🐱
> 儿童双语趣味打字与键盘指法启蒙程序


一款专为儿童设计的沉浸式双语打字互动应用，将**英语单词拼写学习**、**自然拼读发音**与**键盘盲打指法**紧密结合。

---

## ✨ 核心特色

1. **超大字号与 Q 弹手感（Big & Bouncy）**
   - 单词字母采用 **72px+ 巨幅圆润大字体**，每个字母像果冻般具有物理弹跳压扁动效（Jelly Squish & Bounce）。
   - 3D 粘土质感虚拟按键，按下即时下沉回弹，敲击感爽快。

2. **音形意结合：清晰中文释义与纯正双语朗读**
   - 单词卡片包含可爱的 **卡通 Emoji、超大英文拼写、清晰亲切的少儿常用中文释义**（如 `cat -> 猫咪`，`run -> 跑步`）。
   - 内置 Web Speech API 纯正美式英语发音与中文朗读，敲完即读，点击中文也能随时重听。

3. **专设章节：苹果键盘（Magic Keyboard）认知启蒙**
   - **寻找 F 和 J 的小雷达**：引导孩子摸到键盘基准键位上的小横杠凸起。
   - **彩虹十指分工**：十指颜色与按键一一对应，大拇指负责空格键跳跳床。
   - **认识苹果超能力键**：`Space 空格跳跳床`、`Delete ⌫ 小橡皮擦`、`Return ↩ 换行火箭`、`Command ⌘ 花键`、`Shift ⇧ 大写变身卡`。
   - 交互式互动闯关，逐关解锁探险家勋章与“苹果键盘小达人”奖杯。

4. **高能极速挑战模式（Time-Attack Mode）**
   - **动态融化倒计时**：允许输入的时间随单词进行不断缩短，倒计时最后 2.5 秒警报变红并伴随心跳加速音效。
   - **3 颗爱心生命值机制**：超时扣心，连击回血，紧张刺激但不绝望。
   - **连击倍率与积分**：Combo 连击触发金色火焰与多倍积分。
   - **错词复盘战报**：挑战结束后生成战报，统计最高连击、最快击破单词，并将错词收入复盘箱。

5. **纯净零外部依赖**
   - 采用原生 **Web Audio API** 实时合成木琴敲击音、泡泡音、通关胜利弦乐与心跳声，无需加载庞大外部音频文件，毫秒级响应。

---

## 🚀 如何运行

直接在任何现代浏览器（Chrome、Edge、Safari、Firefox）中双击打开根目录下的 `index.html` 即可畅玩！

或者在当前目录通过任意简易 HTTP 服务器打开（例如 Python / Node / VSCode Live Server）：
```bash
# 使用 Python 启动本地服务器
python -m http.server 8080
# 然后在浏览器访问 http://localhost:8080
```
